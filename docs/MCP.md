# Model Context Protocol (MCP) Integration

Asila acts as an **MCP Server**, allowing AI assistants (like Cursor, Claude Desktop, or Windsurf) to securely query your internal documents, code repositories, and notes without requiring you to manually copy and paste context.

## Automatic Configuration (Recommended)

The easiest way to connect your local IDE or AI assistant to Asila is by using the CLI.

For **Cursor**:
```bash
asila mcp configure --client cursor
```

For **Claude Desktop**:
```bash
asila mcp configure --client claude-desktop
```

This command will automatically locate your client's configuration file (e.g., `~/.cursor/mcp.json` or `claude_desktop_config.json`) and inject the required Asila configuration. It will securely pull your local `ASILA_API_KEY` environment variable.

## Available MCP Tools

Once connected, your AI assistant will have access to the following tools:

- `search_knowledge`: Performs hybrid (semantic + keyword) search across your entire indexed organization.
- `list_sources`: Lists all repositories, documents, and folders that Asila has indexed.
- `get_document_content`: Retrieves the exact raw text or markdown content of a specific indexed document for deeper analysis.

*(Administrative operations like ingesting data or managing API keys are intentionally excluded from the MCP toolset for security reasons. Use the `asila` CLI for those tasks.)*

## Manual Configuration (Fallback)

If you are using a custom MCP client or the CLI configuration fails, you can manually configure your client.

Add the following to your MCP client's configuration file:

```json
{
  "mcpServers": {
    "asila": {
      "command": "docker",
      "args": [
        "compose",
        "exec",
        "-T",
        "-e",
        "ASILA_API_KEY=your_actual_api_key_here",
        "api",
        "python",
        "-m",
        "api.main"
      ],
      "env": {
        "ASILA_API_KEY": "your_actual_api_key_here"
      }
    }
  }
}
```

*Note: Replace `your_actual_api_key_here` with the API key generated by `asila init`.*
